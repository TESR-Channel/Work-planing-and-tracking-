# TESR Board — Work Planning & Tracking

🔗 ใช้งาน: https://track.tesrshop.com/ (หน้าลูกค้า: https://track.tesrshop.com/track.html)  ·  ▶ [วิดีโอสอนใช้ครบทุกฟังก์ชัน](tutorial.mp4)

ระบบติดตามงานแบบการ์ด (สไตล์ Trello) + แดชบอร์ดวัดผลทีม + 🚚 ลิงก์ติดตามออเดอร์สำหรับลูกค้า ของ TESR Co., Ltd.

| ส่วน | ใช้อะไร |
|---|---|
| หน้าเว็บ | `index.html` ไฟล์เดียว บน GitHub Pages · ธีม Dark/Light ตาม CI TESR |
| ฐานข้อมูล | Google Sheet **TESR Board DB** (แท็บ Members / Boards / Lists / Cards / Activity) |
| ไฟล์แนบ | Google Drive โฟลเดอร์ **TESR Board / ไฟล์แนบ** |
| API | Google Apps Script `Code.gs` (Web App) |
| ล็อกอิน | อีเมล + เบอร์โทร จาก Sheet ระบบลงเวลา (Work tracking log › Employees) · Admin ใช้บัญชี admin ของระบบลงเวลา |

## ติดตั้ง
1. เปิด Sheet *TESR Board DB* → Extensions → Apps Script → วางโค้ดจาก `Code.gs`
2. เลือกฟังก์ชัน `setup` → Run → อนุญาตสิทธิ์
3. Deploy → New deployment → Web app · Execute as **Me** · Who has access **Anyone** → คัดลอก URL
4. ใส่ URL ใน `CONFIG.API_URL` ของ `index.html`
5. GitHub → Settings → Pages → Branch `main` / root

## การ์ด 2 ประเภท
- 📌 **งาน** — ต้องมีกำหนดส่ง · สี: 🟢 ตามแผน · 🟡 ใกล้กำหนด (≤2 วัน) · 🔴 เลยกำหนด · นับใน KPI
- 📁 **ข้อมูล / ฝากไฟล์** — ไม่ต้องมีกำหนดส่ง · ไม่นับใน KPI

## สิทธิ์
- **พนักงาน / เด็กฝึกงาน** — เห็นแดชบอร์ดและหน้าทีมเฉพาะของตัวเอง
- **Admin** — เห็นทั้งทีม และเลือกดูแดชบอร์ดรายบุคคลได้

## เส้นทางงาน & คะแนน KPI
- ลากการ์ดไปขั้นถัดไป → เลือก **คนรับช่วง** + ฝากข้อความ (ส่งต่องาน)
- กด ◯ ในการ์ด หรือย้ายเข้าคอลัมน์เสร็จ = **ปิดงาน** → ทุกคนที่มีส่วนร่วมได้แต้ม
- ขนาดงาน: ● งานทั่วไป 1 · ◆ งานกลาง 3 · ⭐ โปรเจกต์/งานใหญ่ 5
- เดี่ยว 100% · ทีม คนละ 60% · ส่งเลยกำหนด ×0.5 · Admin ที่แค่ตรวจรับไม่นับเป็นทีม
- หมวดผลงาน: 🔧 งานประจำ ×1 · 🧪 พัฒนาผลิตภัณฑ์/R&D ×1.5 · 💡 ริเริ่มสินค้า/ไอเดียใหม่ ×2 · 📈 พัฒนาองค์กร (ใบรับรอง, BOI, Marketplace, ตลาดใหม่) ×2
- 💡 ผู้ริเริ่มงานหมวดพัฒนา ได้โบนัส +1 แต้ม
- ปรับตัวเลขได้ที่ `SIZES` / `IMPACT` / `SCORE` ใน index.html

## KPI Score (0–100)
🏆 ผลงาน 60% (แต้ม ÷ เป้า/เดือน) + ✅ คุณภาพ 20% (ตรงเวลา · ผ่านรอบแรก · ไม่เลื่อนกำหนด) + 🤝 ทีมเวิร์ก 20% (งานทีม + ส่งต่อ + 🙏)
- 🦺 Safety = เงื่อนไขระงับโบนัส · ข้อมูลประกอบ: 🚀 พัฒนาบริษัท, ⭐ ความพอใจลูกค้า, 💼 ปิดดีล, ⏱ Cycle time
- หมวดเพิ่ม: 📚 ถ่ายทอดความรู้ ×1.5 · 🛠 ของใช้ซ้ำ ×1.5 · 🎓 พัฒนาตัวเอง ×1.2
- 🙏 ขอบคุณเพื่อน: +0.5 แต้ม · ส่งได้ 3 ครั้ง/เดือน · คนเดิมสัปดาห์ละครั้ง
- เป้าแต้ม/เดือนตั้งรายคนได้ในหน้า ⚙️ (ค่าเริ่มต้น 10)

## 🚚 ลิงก์ติดตามออเดอร์สำหรับลูกค้า (`track.html`)
ใช้แทน Trello สำหรับงาน Shop / Academy / Logistics — พนักงานทำงานในบอร์ดตามปกติ ลูกค้าเห็นสถานะจากลิงก์ของออเดอร์ตัวเอง · คู่มือพนักงาน: https://claude.ai/artifact/FW54Uz2Fv6Sq9vjvmqDPw1
**เอกสารบัญชียังออกจาก FlowAccount เหมือนเดิม** ระบบนี้แค่เก็บลิงก์เอกสาร (Paynow) มาแสดง

**ตั้งค่าครั้งเดียว (Admin)**
1. อัปเดต `Code.gs` ใน Apps Script → Run `setup` (สร้างแท็บ *Payments* และ *Customers*)
2. Deploy → **Manage deployments → ✏️ Edit → Version: New version → Deploy** (URL เดิมใช้ต่อได้)
3. บนบอร์ด กด ⋯ ของแต่ละคอลัมน์ → ใส่ **👁 ชื่อขั้นที่ลูกค้าเห็น** (เช่น ใบเสนอราคา → *ออกใบเสนอราคา*, PO Approved → *ยืนยันคำสั่งซื้อ*)
   - คอลัมน์ที่เว้นว่าง = ขั้นภายใน ลูกค้าเห็นเป็นขั้นก่อนหน้า · ถ้าทั้งบอร์ดไม่ตั้งเลย ลูกค้าเห็นชื่อคอลัมน์ทั้งหมด
   - คอลัมน์ที่ตั้งสถานะ ✅ เสร็จ = ลูกค้าเห็น 100%

**ใช้งานต่อออเดอร์ (พนักงาน)**
1. เปิดการ์ด → **🚚 เปิดลิงก์ติดตาม** → ใส่เลขอ้างอิง, รายการ, วันที่คาดว่าจะได้รับ, ลิงก์ FlowAccount, เลขพัสดุ
2. ใส่ **🔒 เลขผู้เสียภาษี / เบอร์โทรลูกค้า** — ลูกค้าต้องกรอกอย่างใดอย่างหนึ่งก่อนเห็นเอกสาร สลิป เลขพัสดุ และหลักฐาน
3. ลูกค้ามีหลายออเดอร์ → กด **สร้าง PIN ลูกค้า** → ลูกค้าเข้า `track.html` ด้วยเลขภาษี/เบอร์ + PIN เห็นทุกออเดอร์ของตัวเอง แยกรายการ
4. กด **คัดลอกข้อความส่งลูกค้า** → วางใน LINE OA / Facebook / อีเมล
5. ย้ายการ์ดตามงานจริง → หน้าลูกค้าอัปเดตเอง
6. ใส่ **เลข INV** → ระบบหาโฟลเดอร์หลักฐานจากแอป Handover ให้อัตโนมัติ (หรือวางลิงก์ Drive เอง)

**💳 หลักฐานการชำระเงิน** — ลูกค้าแนบสลิปจากหน้าติดตาม (สถานะ ⏳ รอตรวจสอบ, การ์ดขึ้นป้าย 💳) → พนักงานกด ✓ ยืนยันรับเงิน / ✕ ไม่ถูกต้อง · พนักงานแนบสลิปเองได้ · ทั้งสองฝั่งเห็นชุดเดียวกัน

**ความปลอดภัย** — ลิงก์ใช้รหัสสุ่ม 14 ตัว (ไม่ใช่เลข QT) · ไม่ยืนยันตัวตน = เห็นแค่ชื่อรายการและขั้นตอน · กรอกผิด/PIN ผิด 8 ครั้ง ล็อก 15 นาที · token ลูกค้าเซ็นด้วยกุญแจแยกจากพนักงาน ใช้เรียก API ภายในไม่ได้ · ลูกค้าไม่เห็นผู้รับผิดชอบ คอมเมนต์ เช็คลิสต์ ไฟล์แนบภายใน
